# Disciplina de Inteligência Artificial

Repositório destinado ao armazenamento dos notebooks e atividades desenvolvidos durante a disciplina de Inteligência Artificial do curso de Engenharia de Software.

## Sobre o repositório

Este repositório contém os exercícios práticos desenvolvidos ao longo da disciplina, utilizando principalmente a linguagem de programação Python e o Google Colab como ambiente de desenvolvimento.

As atividades têm como objetivo aplicar conceitos de programação, lógica e algoritmos, contribuindo para o desenvolvimento dos conhecimentos necessários para a compreensão e aplicação de conceitos relacionados à Inteligência Artificial.

## Conteúdo

Os notebooks presentes neste repositório reúnem os exercícios propostos durante a disciplina. Entre os conteúdos abordados estão:

- Variáveis e tipos de dados;
- Estruturas condicionais;
- Estruturas de repetição;
- Listas e dicionários;
- Manipulação de strings;
- Funções;
- Algoritmos de busca e ordenação;
- Matrizes;
- Manipulação de dados;
- Criptografia e Cifra de César;
- Outros conceitos e atividades propostos ao longo da disciplina.

Cada exercício contém comentários e explicações referentes à lógica utilizada para a resolução da atividade, conforme as orientações da disciplina.

## Arquivos

Os arquivos `.ipynb` correspondem aos notebooks desenvolvidos no Google Colab e disponibilizados neste repositório.

Novos notebooks e atividades serão adicionados conforme o desenvolvimento da disciplina.
